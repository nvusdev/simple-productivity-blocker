Deep Enforcement

Unlike browser extensions, SPB works at the system level. It modifies your hosts file directly, ensuring blocks survive browser restarts, incognito mode, and proxy attempts.

OS-Level Process Control

Quick Install Guide

Windows

  1. Download & Extract: Download the .zip file and extract all files to a folder.
  2. Run Installer: Launch spb_installer.exe from the extracted folder.
  3. Elevate: Grant Administrator privileges when prompted.
  4. Launch: Open "Simple Productivity Blocker" and start focusing.

Linux

  1. Download & Extract: Download the .zip file and extract all files.
  2. Run Installer: Open terminal in the folder and run sudo ./install.sh.
  3. Elevate: Provide your root password to allow system-level blocking.
  4. Launch: Open SPB from your applications menu.
