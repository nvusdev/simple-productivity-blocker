Deep Enforcement

Unlike browser extensions, SPB works at the system level. It modifies your hosts file directly, ensuring blocks survive browser restarts, incognito mode, and proxy attempts.

OS-Level Process Control

Our background daemon monitors active processes and command-line arguments. If a restricted app, file, or folder is accessed, it's terminated instantly with high-performance psutil integration.

Quick Install Guide

  1. Download & Extract: Download the .zip file for your OS and extract all files to a folder.
  2. Run Installer: Launch spb_installer.exe (Windows) or run sudo ./install.sh in your terminal (Linux).
  3. Elevate: Grant Administrator/Root privileges when prompted to allow SPB to manage system rules.
  4. Launch: Open "Simple Productivity Blocker" from your desktop and start focusing.
